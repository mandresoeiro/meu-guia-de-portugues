# Meu Guia de Português

Guia pessoal de consulta ao português brasileiro. Abra `index.html` diretamente no navegador. A busca, os exemplos, os favoritos e as anotações funcionam sem instalação, conta ou conexão com a internet.

## Organizar o conteúdo

- `conteudo.js` contém o índice por assuntos, as regras e os exemplos comentados. Cada registro tem identificador, categoria, título, resposta curta, explicação, exemplos e uma observação opcional.
- `guia.js` implementa a busca, a navegação e o armazenamento das preferências.
- `estilo.css` contém os estilos para celular e computador.

Os favoritos e as anotações ficam no armazenamento deste navegador. Uma mudança de navegador ou endereço pode abrir outro conjunto de preferências. O guia cobre os principais assuntos da gramática e pode receber mais regras sem mudança de estrutura.
